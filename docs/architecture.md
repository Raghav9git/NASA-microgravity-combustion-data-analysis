# Application Architecture

Starter architecture:
- Frontend: to be coordinated with the UI/UX designer.
- Backend: FastAPI.
- Initial local database: SQLite for a simple first setup test.
- Planned scientific database: PostgreSQL, after data requirements are understood.
- Data processing and ML: Python, pandas, NumPy, scikit-learn.
- AI retrieval and LLM integration: planned after source data is inspected.

This is a starter scaffold, not a completed application.
