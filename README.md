# Flame in Freefall: AI-Powered Fire Safety Insights from Microgravity Combustion Data

NASA Space Apps Challenge 2026 project focused on exploring microgravity combustion data and developing an AI-powered system for fire-safety analysis.

## Overview

This project aims to organize NASA's microgravity combustion research and provide an interactive platform to explore, compare, and analyze experimental data.

The planned system will combine:

- NASA combustion data
- Data analysis and visualization
- Machine learning
- AI-assisted research and interpretation
- An interactive web dashboard

## Current Status

**Planning and Research Phase**

The repository currently contains the initial project setup. NASA datasets, data processing, machine learning models, and the dashboard will be developed in later stages.

## Planned Technology

- Python
- PostgreSQL
- Scikit-learn
- React / Next.js
- FastAPI
- AI / RAG

## Goal

To make NASA's microgravity combustion research easier to explore and analyze, while providing evidence-based insights related to fire safety in human space exploration.
